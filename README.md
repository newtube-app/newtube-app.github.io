# newtube-app.github.io

The website of [NewTube](https://github.com/aleixrodriala/newtube), served at
<https://newtube-app.github.io/>.

This repo is written by a workflow: every change to `website/` in
[aleixrodriala/newtube](https://github.com/aleixrodriala/newtube/tree/main/website) is copied
here by [`pages.yml`](https://github.com/aleixrodriala/newtube/blob/main/.github/workflows/pages.yml).
Edit the site there; changes made here are overwritten.
